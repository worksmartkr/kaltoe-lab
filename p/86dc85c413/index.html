엑셀 작업 속도 확 올려주는 단축키 7개

1빠른 채우기

옆 칸에 예시 하나만 입력하고 누르면 패턴을 읽어서 나머지를 채워줘요. 이름 분리, 전화번호 형식 바꾸기에 딱.

Ctrl + E

TIP 함수 없이 텍스트 쪼개기 끝

2필터 켜고 끄기

머리글 행에 커서 두고 누르면 필터가 바로 생겨요. 한 번 더 누르면 해제.

Ctrl + Shift + L

3범위를 표로 만들기

표로 바꾸면 행을 추가해도 수식·서식이 자동으로 따라와요. 피벗 원본으로도 최고.

Ctrl + T

TIP 범위가 늘어나도 참조가 안 깨져요

4자동 합계

숫자 아래 빈 칸에서 누르면 SUM 수식이 범위까지 잡혀서 들어가요.

Alt + =

5끝까지 한 번에 선택

데이터가 끝나는 지점까지 한 번에 선택. 마우스로 스크롤하며 드래그할 필요 없어요.

Ctrl + Shift + ↓

6오늘 날짜 입력

오늘 날짜가 값으로 들어가요. TODAY() 함수와 달리 내일 열어도 안 바뀌어요.

Ctrl + ;

7절대참조 전환

수식 입력 중 셀 주소에서 누르면 $A$1 → A$1 → $A1 → A1 순서로 바뀌어요.

F4

TIP 수식 밖에선 '마지막 작업 반복'
